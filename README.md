# InvoiceBuddy

AR Diagnostic: Review invoice/payment data and return a report showing open invoices, unapplied payments, short pays, missing information, and exceptions.

AR Tracker helps small businesses turn invoice and payment data into a clear report showing what is open, what is paid, what is unmatched, what is missing, and what needs review.

Ideal for:

bookkeepers
CPAs
tax preparers
small business owners
office managers
contractors/service businesses
QuickBooks users with messy AR
