# AR Tracker

Static GitHub Pages demo for AR Tracker, a service-style invoice, payment, remittance, exception, and CPA/bookkeeper-ready status review prototype.

## GitHub Pages setup

Use these repository settings:

- Source: Deploy from a branch
- Branch: main
- Folder: /docs

The public page should load from:

```text
https://x22abc.github.io/InvoiceBuddy/
```

## Files

```text
docs/index.html
README.md
LICENSE
```

`docs/index.html` is intentionally a single static file with embedded CSS and JavaScript so the page can be uploaded directly to GitHub without a build step.
